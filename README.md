# Internet in One Word

A small Python program that writes a single word capturing the internet to /output/entry.txt.

## How it works

Run `MAKEFUN_OUTPUT_DIR=./output python3 main.py` to write the entry to ./output/entry.txt. The program writes the word and nothing else, and prints nothing.
